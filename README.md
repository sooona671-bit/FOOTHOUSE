# FOOT HOUSE

Premium footwear and fashion essentials app.

**Stack:** TanStack Start, React 19, Tailwind CSS 4, Supabase (auth + database + storage), Drizzle migrations.

## Setup

Poora step-by-step guide (Supabase, database, login, email, Google, admin, deploy, aur kya kahan rakhna hai): [docs/SETUP.md](docs/SETUP.md)

Quick start:

```sh
cp .env.example .env   # fill in your Supabase URL + publishable key
# run supabase/setup.sql in the Supabase SQL editor
bun install            # or: npm install
bun run dev            # or: npm run dev
```
